# AIHub Browser 1.85.0

- Adds Ember Vinyl, Silver Wave, Silver Classic and Battle Artwork to the built-in AIHub DJ.
- Makes colour palettes work across DJ skins, with a Skin original option.
- Shows track artwork across the entire record, with the silver hub used only when artwork is absent.
- Refines console proportions, compact controls, time displays and video-panel fit.
- Leaves Vinyl Club and Battle Black out of the skin picker.
- Adds a DJ Settings shortcut to the browser's existing update check. The browser retains its own release feed and update system.

Version metadata is updated to 1.85.0. A version tag can use the existing release workflow to build and publish the browser installers.
