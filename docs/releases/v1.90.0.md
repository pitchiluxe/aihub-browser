# AIHub Browser 1.90.0 — Security Center

## New

- **Security Center:** Defender protection status, signature freshness, scan controls, and a local security timeline. Open it from the sidebar or the shield in the address toolbar.
- **Download Guardian:** completed downloads are scanned automatically. AIHub checks file contents again before opening and rescans changed or expired results. Confirmed detections and ambiguous threat/error results block opening. Failed or unavailable scans are explicitly unverified and require a native confirmation.
- **Defender controls:** file, folder, quick, and full scans, plus a shortcut to Windows Security. File/folder scans ignore exclusions for that scan, inspect archives, and report without applying remediation. They do not alter exclusions or disable real-time protection. Quick/full scans follow Windows policy.
- **Phishing indicators:** warns about misleading URL credentials, internationalized domains, insecure password submissions, and cross-origin password forms on loaded pages. A toolbar warning opens the evidence timeline.
- **Local HTML inspection:** statically checks HTML for remote scripts, encoded/dynamic JavaScript, external frames, and password prompts before loading. Suspicious or uninspectable files require a decision before execution.
- **Local Ollama analyst:** reviews Defender status and recent security evidence with an installed local model. Cloud models, remote endpoints, redirects, and cloud fallback are disabled. The analyst has no execution or antivirus-setting tools.

## Fixed

- Opening `.html` and `.htm` paths from Windows now produces proper file URLs, including spaces, Unicode, `#`, and `%` in filenames. Cold starts and launches into an existing browser use the same parser.
- The address bar preserves `file://` URLs instead of treating them as web searches or prefixing HTTPS.

## Scope

Defender controls require Windows and an active Defender installation. Other platforms keep browser indicators and local analysis, with antivirus status explicitly unavailable. Heuristic findings and “No threats found” do not guarantee safety. Incognito findings stay in memory; Windows maintains its own antivirus history. This release does not add system-wide process monitoring, firewall changes, or AI-controlled deletion/quarantine restoration.

## Validation

- Automated policy, command-injection, scan failure, changed-file, quarantine, private-history, IPC ownership, and UI error-state tests.
- Real Defender scan of a harmless HTML file and real Qwen analysis through an isolated loopback Ollama instance.
- Electron end-to-end checks for HTML launch, Security Center, visible phishing indicators, cancelled HTML preflight, and a real automatically scanned download.
- Incognito privacy regression: 71/71 checks passed, including restart/crash persistence and an on-disk private-data search.
