# AIHub Browser 1.88.3

## Bible
- **Monthly reading:** Bible Study → Study now opens on a reading plan for the month. Each month has a theme, a verse to carry through it, a short introduction and an encouragement for each week, with a reading for every day: Genesis in January, Proverbs by date in May, psalms of thanksgiving in November, Isaiah through Advent and Luke 2 on Christmas Day. Mark each day read, see how many days you have to catch up, and look ahead to next month.
- **Natural reading voice:** scripture can now be read by a natural, human-sounding voice instead of the robotic system one. Install it once from Settings → Bible (about 165 MB); after that it works offline and nothing you read leaves your computer. Choose from five voices (Heart, Bella, Michael, Emma, George) and set the reading pace. English versions only; French keeps the system voice.
- **Reads like a person:** both voices now pause at commas and full stops, rest after announcing the reference, slow down on the last line, and read "5:16–18" as "5 verse 16 to 18". "LORD" is said as a word.

## Build
- Smaller downloads: the Linux AppImage no longer carries the GPU (CUDA) libraries of the voice engine, which only ever runs on the CPU — back from about 370 MB to roughly the size it was before 1.88. Windows and macOS installers carry only the app again, as fixed in 1.88.2.
