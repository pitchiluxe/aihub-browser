# AI DJ Core Implementation Plan (plan 1 of 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn AIHub DJ into an AI DJ that builds and mixes a flowing set from a one-line brief, follows spoken/typed instructions as standing rules, and shows it on a Cinema stage — with the existing console behind "Take the decks".

**Architecture:** Pure, tested units do the thinking — `measureFacts` (tempo/key/energy/cue points from audio), `parseBrief`, `parseInstruction` (+ `SetRules`), `rankCandidates` (planner) — and a `SetConductor` drives them against injected I/O (YouTube search, 2× fact scans, the AutoMixer's `hooks.next()`). Facts persist main-side in a debounced JSON store. The stage is a React overlay inside the existing `Console` so decks and players stay mounted.

**Tech Stack:** Electron 44, React 18, TypeScript, Web Audio (ScriptProcessor capture of a hidden YouTube player at 2×), Vitest (+ jsdom), existing DJ engine.

**Spec:** `docs/superpowers/specs/2026-10-12-ai-dj-stage-design.md` (plan 2 — the five extra stage themes — is out of scope here; this plan ships the **Cinema** theme only).

## Global Constraints

- Fact scans run at **2×** with `keyLock` off (exact time compression); one scan player at a time, deck id `F-scan`; scans pause while a transition is running.
- Key confidence < 0.4 → treated as unknown (neutral key score). Tempo confidence from first/second-half agreement.
- Planner weights: tempo 0.30 · key 0.20 · energy 0.20 · taste 0.20 · discovery 0.10. Tempo full within ±3% (or half/double), linear to 0 at ±8%. Camelot same/±1/relative = 1.0, ±2 = 0.5, else 0.2.
- Discovery default share 0.25; no repeated track in a set; no artist within 45 minutes; disliked tracks never.
- Lookahead 3 tracks. `SetConductor.next()` never returns `undefined` while any unplayed, unbanned candidate exists.
- Set rules persist until removed: `banArtist`, `onlyGenres`, `moreGenre`, `lessGenre`, `tempoRange`, `minEnergy`, `maxEnergy` (optional `untilMs`), `noExplicit`, `stopAfterCurrent`, `sequence`, `playNext`, `discoveryBurst`, `favoritesOnly`.
- Every instruction produces a confirmation line shown on the stage; rules are shown as removable chips.
- The AI model is used only for text the rules cannot parse; its reply must be whitelisted rule/action JSON.
- `TrackFacts` persisted via main `createManagedJsonStore('dj-facts.json')`, capped at 5,000 entries (oldest `at` evicted). Writes through `handlePersistent` (refused from Incognito).
- Incognito: sets play; no taste events, facts, or set log are written.
- No synchronous disk I/O; stage animations pause when the tab is hidden; YouTube player pictures stay hidden unless the stage shows video.
- Scope note: the stage takes **typed** instructions; spoken input keeps working through the existing AI DJ panel's voice button and is routed through the same `askDj` pipeline in plan 2. Plan 2 also owns the five extra themes and the theme picker.

## Review Focus

1. **Instructions that sound alike but mean opposites** ("no slow songs" vs "slow songs please"; "calm down" as a song title vs a mood) — must never produce the opposite action.
2. **Every candidate filtered out by rules** (e.g. `onlyGenres` + `tempoRange` too narrow) — the conductor must relax limits and keep playing, and say it did, never go silent.
3. **The user takes the decks mid-transition, then returns** — the conductor must resume from what is actually playing, not from its stale lookahead head.
4. **A scan that never finishes or a video that is region-blocked** — must be marked unplayable and never loaded on a deck.
5. **AutoMixer asks for `next()` while the lookahead is still analysing** — must get a safe un-analysed pick, not `undefined` (which switches Automix off).

Each is pinned by a test in Tasks 6, 8, 9, 9 and 9 respectively.

```ts
  if (!bestBpm || best <= 0) return null

  // ⅔ guard. A song at 160 BPM puts strong onsets at 1.5× the 107 BPM lag
  // (every third half-beat lands on a beat), and the 120-centred prior then
  // favours 107. If the tempo one and a half times faster explains the
  // onsets nearly as well WITHOUT the prior, it is the real beat.
  const raw = (bpm: number) => score(bpm) / (0.75 + 0.25 * Math.exp(-Math.pow(Math.log2(bpm / 120), 2) / (2 * 0.5 * 0.5)))
  const up = bestBpm * 1.5
  if (up <= MAX_CORRECTED_BPM && raw(up) >= TWO_THIRDS_RATIO * raw(bestBpm)) {
    let bestUp = 0
    for (let bpm = up - 1.5; bpm <= up + 1.5 + 1e-9; bpm += 0.1) {
      const s = raw(bpm)
      if (s > bestUp) { bestUp = s; bestBpm = bpm }
    }
  }
  const rounded = Math.round(bestBpm)
  return Math.abs(bestBpm - rounded) < 0.25 ? rounded : Math.round(bestBpm * 10) / 10
}

/** Corrected readings may go above the 180 search ceiling (drum & bass, fast pop). */
const MAX_CORRECTED_BPM = 200
/** How close the 3/2 tempo's raw comb score must come to the winner's. Tuned on the real-song fixtures. */
const TWO_THIRDS_RATIO = 0.9
```

```ts
// src/renderer/src/components/dj/ai/types.ts
/** What the AI DJ knows about a track from measuring its audio. */
export interface TrackFacts {
  bpm: number | null
  /** 0..1 — 1 when both halves of the song agree on the tempo. */
  bpmConfidence: number
  /** Camelot code ("8A"), null when the key is unclear. */
  camelot: string | null
  keyConfidence: number
  /** 0..1 — loudness and pace together. */
  energy: number
  /** Seconds where the music proper starts / the ending begins — mix points. */
  introEndSec: number
  outroStartSec: number
  durationSec: number
  /** False when the track could not be scanned (blocked, stalled): never load it. */
  playable: boolean
  /** When measured — the facts store evicts the oldest first. */
  at: number
}

export type MeasuredFacts = Omit<TrackFacts, 'playable' | 'at'>

/** One key per track, whichever source it came from. */
export function trackId(t: { youtubeId?: string; path: string }): string {
  return t.youtubeId ? `yt:${t.youtubeId}` : `file:${t.path}`
}
```

```ts
// src/renderer/src/components/dj/engine/measureFacts.ts
// Everything the set planner needs to know about a track, measured from its
// audio: tempo (with a confidence), key, energy and where to mix in and out.
// Pure — the same function runs in a worker for live scans and in tests.
import type { MeasuredFacts } from '../ai/types'
import { buildEnvelope, detectBpm, onsetCurve, ENV_RATE } from './analysis'
import { detectKey } from './key'

/** Below this the key detector is guessing (see the 2026-10-12 probe). */
const KEY_CONFIDENCE_FLOOR = 0.4

function perSecondRms(pcm: Float32Array, rate: number): Float32Array {
  const secs = Math.floor(pcm.length / rate)
  const out = new Float32Array(secs)
  for (let s = 0; s < secs; s++) {
    let sum = 0
    const from = Math.floor(s * rate), to = Math.floor((s + 1) * rate)
    for (let i = from; i < to; i++) sum += pcm[i] * pcm[i]
    out[s] = Math.sqrt(sum / Math.max(1, to - from))
  }
  return out
}

const median = (a: Float32Array) => { const s = Array.from(a).sort((x, y) => x - y); return s.length ? s[Math.floor(s.length / 2)] : 0 }

export function measureFacts(pcm: Float32Array, rate: number): MeasuredFacts {
  const durationSec = pcm.length / rate
  const onset = onsetCurve(buildEnvelope(pcm, rate))
  const bpm = detectBpm(onset)

  // Tempo confidence: does each half of the song agree with the whole?
  let bpmConfidence = 0
  if (bpm !== null) {
    const half = Math.floor(onset.length / 2)
    const agrees = (x: number | null) => x !== null && Math.abs(x - bpm) / bpm < 0.02
    const a = half >= ENV_RATE * 10 ? detectBpm(onset.subarray(0, half)) : null
    const b = half >= ENV_RATE * 10 ? detectBpm(onset.subarray(half)) : null
    bpmConfidence = agrees(a) && agrees(b) ? 1 : agrees(a) || agrees(b) ? 0.7 : 0.4
  }

  const key = detectKey(pcm, rate)
  const keyOk = !!key && key.confidence >= KEY_CONFIDENCE_FLOOR

  // Energy: how loud the busy part of the song is, blended with its pace.
  const rms = perSecondRms(pcm, rate)
  const loudSorted = Array.from(rms).sort((x, y) => y - x)
  const loudHalf = loudSorted.slice(0, Math.max(1, Math.floor(loudSorted.length / 2)))
  const meanLoud = loudHalf.reduce((n, v) => n + v, 0) / loudHalf.length
  const db = 20 * Math.log10(Math.max(1e-6, meanLoud))
  const loudness = Math.min(1, Math.max(0, (db + 30) / 24))           // -30 dB → 0, -6 dB → 1
  const pace = bpm === null ? 0.3 : Math.min(1, Math.max(0, (bpm - 80) / 90)) // 80 → 0, 170 → 1
  const energy = Math.round((0.6 * loudness + 0.4 * pace) * 100) / 100

  // Mix points: where a rolling 4 s loudness first / last reaches 70% of the
  // song's typical (median) loudness.
  const typical = median(rms)
  const rolling = (i: number) => { let s = 0, n = 0; for (let k = i; k < Math.min(rms.length, i + 4); k++) { s += rms[k]; n++ } return n ? s / n : 0 }
  let introEndSec = 0, outroStartSec = Math.floor(durationSec)
  if (typical > 1e-4) {
    for (let i = 0; i < rms.length; i++) if (rolling(i) >= 0.7 * typical) { introEndSec = i; break }
    for (let i = rms.length - 4; i >= 0; i--) if (rolling(i) >= 0.7 * typical) { outroStartSec = i + 4; break }
  }

  return {
    bpm, bpmConfidence,
    camelot: keyOk ? key!.camelot : null,
    keyConfidence: key ? key.confidence : 0,
    energy, introEndSec, outroStartSec, durationSec,
  }
}
```

```ts
// src/main/dj/facts.ts
// The AI DJ's measured facts per track. Measuring a YouTube song costs a
// two-minute scan, so results are kept — but bounded, and validated, since the
// renderer is the only writer.
export interface TrackFacts {
  bpm: number | null; bpmConfidence: number; camelot: string | null; keyConfidence: number
  energy: number; introEndSec: number; outroStartSec: number; durationSec: number; playable: boolean; at: number
}

const unit = (v: unknown) => typeof v === 'number' && v >= 0 && v <= 1
const secs = (v: unknown) => typeof v === 'number' && Number.isFinite(v) && v >= 0 && v < 6 * 3600

export function validFacts(x: unknown): x is TrackFacts {
  const f = x as TrackFacts
  return !!f && typeof f === 'object'
    && (f.bpm === null || (typeof f.bpm === 'number' && f.bpm > 30 && f.bpm < 300))
    && unit(f.bpmConfidence) && unit(f.keyConfidence) && unit(f.energy)
    && (f.camelot === null || (typeof f.camelot === 'string' && /^(1[0-2]|[1-9])[AB]$/.test(f.camelot)))
    && secs(f.introEndSec) && secs(f.outroStartSec) && secs(f.durationSec)
    && typeof f.playable === 'boolean' && typeof f.at === 'number'
}

export const FACTS_CAP = 5000
const ID = /^(yt:[A-Za-z0-9_-]{11}|file:.{1,1024})$/

export function putFacts(all: Record<string, TrackFacts>, id: string, f: TrackFacts, cap = FACTS_CAP): Record<string, TrackFacts> {
  if (!ID.test(id) || !validFacts(f)) return all
  const next = { ...all, [id]: f }
  const keys = Object.keys(next)
  if (keys.length > cap) {
    keys.sort((a, b) => next[a].at - next[b].at)
    for (const k of keys.slice(0, keys.length - cap)) delete next[k]
  }
  return next
}
```

```ts
// In-memory view of the main-process facts store. Reads are synchronous for
// the planner; `load` fills the cache for a batch of candidates first.
import type { TrackFacts } from './types'

const cache = new Map<string, TrackFacts>()
const api = () => (window as any).electronAPI?.dj?.facts

export const factsCache = {
  get(id: string): TrackFacts | null { return cache.get(id) ?? null },
  async load(ids: string[]): Promise<void> {
    const missing = ids.filter(id => !cache.has(id))
    if (!missing.length || !api()) return
    try {
      const got = await api().getMany(missing) as Record<string, TrackFacts>
      for (const [id, f] of Object.entries(got || {})) cache.set(id, f)
    } catch { /* offline store: measure again */ }
  },
  put(id: string, f: TrackFacts): void {
    cache.set(id, f)
    void api()?.put(id, f).catch(() => {})
  },
}
```

```ts
// src/renderer/src/components/dj/engine/factScan.ts
// Measures a track before it plays. A YouTube song is played silently on its
// own hidden scan player at 2× with key-lock off — an exact time compression —
// and captured; reading the capture at half rate restores the song exactly.
// 4× was faster but lost accuracy (2026-10-12 probe). Local files are decoded
// directly. The heavy maths runs in a worker, off the UI thread.
import type { DjTrack } from './DjEngine'
import type { MeasuredFacts } from '../ai/types'
import { captureTab, ytBridge } from './youtubeDeck'

export const FACT_SCAN_RATE = 2
const SCAN_DECK = 'F-scan'
/** Analysis rate after decimation; detectKey reads up to 1.8 kHz. */
const TARGET_RATE = 6000
/** Give up on a scan that makes no progress for this long. */
const STALL_MS = 20_000
/** Hard cap on one scan (a 7-minute song at 2× is 3.5 minutes). */
const MAX_SCAN_MS = 4 * 60_000

export interface FactSource { measure(track: DjTrack, signal: { cancelled: boolean }): Promise<MeasuredFacts | null> }

export function decimate(chunks: Float32Array[], factor: number): Float32Array {
  const total = chunks.reduce((n, c) => n + c.length, 0)
  const out = new Float32Array(Math.floor(total / factor))
  let k = 0, acc = 0, n = 0
  for (const c of chunks) for (let i = 0; i < c.length; i++) {
    acc += c[i]
    if (++n === factor) { if (k < out.length) out[k++] = acc / factor; acc = 0; n = 0 }
  }
  return out
}

let worker: Worker | null = null
let seq = 0
const pending = new Map<number, (r: MeasuredFacts | null) => void>()
function measureInWorker(pcm: Float32Array, rate: number): Promise<MeasuredFacts | null> {
  if (!worker) {
    worker = new Worker(new URL('./facts.worker.ts', import.meta.url), { type: 'module' })
    worker.onmessage = (e: MessageEvent<{ id: number; facts?: MeasuredFacts }>) => {
      pending.get(e.data.id)?.(e.data.facts ?? null); pending.delete(e.data.id)
    }
  }
  const id = ++seq
  return new Promise(resolve => { pending.set(id, resolve); worker!.postMessage({ id, pcm, rate }, [pcm.buffer]) })
}

async function captureYouTube(ctx: AudioContext, videoId: string, signal: { cancelled: boolean }): Promise<{ pcm: Float32Array; rate: number } | null> {
  const yt = ytBridge()
  const loaded = await yt.load(SCAN_DECK, videoId).catch(() => null)
  if (!loaded || (loaded as any).error) { void yt.unload(SCAN_DECK); return null }
  await yt.cmd(SCAN_DECK, 'keyLock', false)
  const stream = await captureTab(await yt.streamId(SCAN_DECK), false).catch(() => null)
  if (!stream) { void yt.unload(SCAN_DECK); return null }
  const src = ctx.createMediaStreamSource(stream)
  const proc = ctx.createScriptProcessor(4096, 1, 1)
  const sink = ctx.createGain(); sink.gain.value = 0
  const chunks: Float32Array[] = []
  proc.onaudioprocess = e => chunks.push(new Float32Array(e.inputBuffer.getChannelData(0)))
  src.connect(proc); proc.connect(sink); sink.connect(ctx.destination)
  await yt.cmd(SCAN_DECK, 'play'); await yt.cmd(SCAN_DECK, 'rate', FACT_SCAN_RATE)
  const started = Date.now(); let lastT = -1, lastMove = Date.now(), complete = false
  try {
    while (!signal.cancelled && Date.now() - started < MAX_SCAN_MS) {
      await new Promise(r => setTimeout(r, 1000))
      const s = await yt.state(SCAN_DECK).catch(() => null) as any
      if (!s) break
      if (s.error) return null
      if (s.paused && !s.ended && !s.ad) void yt.cmd(SCAN_DECK, 'play')
      if (s.ended || (s.d && s.t >= s.d - 1)) { complete = true; break }
      if (Math.abs(s.t - lastT) > 0.01) { lastT = s.t; lastMove = Date.now() }
      else if (Date.now() - lastMove > STALL_MS) return null
    }
  } finally {
    proc.disconnect(); src.disconnect(); sink.disconnect()
    stream.getTracks().forEach(t => t.stop())
    void yt.unload(SCAN_DECK)
  }
  if (signal.cancelled || (!complete && lastT < 30)) return null
  const factor = Math.max(1, Math.round(ctx.sampleRate / (TARGET_RATE * FACT_SCAN_RATE)))
  return { pcm: decimate(chunks, factor), rate: ctx.sampleRate / factor / FACT_SCAN_RATE }
}

async function decodeLocal(ctx: AudioContext, token: string): Promise<{ pcm: Float32Array; rate: number } | null> {
  try {
    const res = await fetch(`aihub-media://${token}/`)
    const buf = await ctx.decodeAudioData(await res.arrayBuffer())
    const ch = Array.from({ length: buf.numberOfChannels }, (_, i) => buf.getChannelData(i))
    const mono = new Float32Array(buf.length)
    for (const c of ch) for (let i = 0; i < c.length; i++) mono[i] += c[i] / ch.length
    const factor = Math.max(1, Math.round(buf.sampleRate / TARGET_RATE))
    return { pcm: decimate([mono], factor), rate: buf.sampleRate / factor }
  } catch { return null }
}

export function createFactSource(ctx: AudioContext): FactSource {
  return {
    async measure(track, signal) {
      const audio = track.youtubeId
        ? await captureYouTube(ctx, track.youtubeId, signal)
        : await decodeLocal(ctx, track.token)
      if (!audio || audio.pcm.length < audio.rate * 20) return null
      return measureInWorker(audio.pcm, audio.rate)
    },
  }
}
```

```ts
// src/renderer/src/components/dj/engine/analysisQueue.ts
// One scan at a time, never during a transition: a scan shares the CPU and
// the network with the decks, and a stuttering blend is the one thing a DJ
// cannot do. Results are cached so a song is only ever measured once.
import type { DjTrack } from './DjEngine'
import type { FactSource } from './factScan'
import { trackId, type TrackFacts } from '../ai/types'

export interface FactsCache { get(id: string): TrackFacts | null; put(id: string, f: TrackFacts): void }

export class AnalysisQueue {
  private chain: Promise<unknown> = Promise.resolve()
  private inflight = new Map<string, Promise<TrackFacts>>()
  private signal = { cancelled: false }
  private waiting = 0
  private readonly isBusy: () => boolean
  private readonly sleep: (ms: number) => Promise<void>
  private readonly now: () => number

  constructor(private source: FactSource, private cache: FactsCache, opts: { isBusy?: () => boolean; sleep?: (ms: number) => Promise<void>; now?: () => number } = {}) {
    this.isBusy = opts.isBusy ?? (() => false)
    this.sleep = opts.sleep ?? (ms => new Promise(r => setTimeout(r, ms)))
    this.now = opts.now ?? Date.now
  }

  known(track: DjTrack): TrackFacts | null { return this.cache.get(trackId(track)) }
  get pending(): number { return this.waiting }

  ensure(track: DjTrack): Promise<TrackFacts> {
    const id = trackId(track)
    const hit = this.cache.get(id)
    if (hit) return Promise.resolve(hit)
    const running = this.inflight.get(id)
    if (running) return running
    this.waiting++
    const job = this.chain.then(async () => {
      while (this.isBusy() && !this.signal.cancelled) await this.sleep(1000)
      const m = this.signal.cancelled ? null : await this.source.measure(track, this.signal).catch(() => null)
      const facts: TrackFacts = m
        ? { ...m, playable: true, at: this.now() }
        : { bpm: null, bpmConfidence: 0, camelot: null, keyConfidence: 0, energy: 0.5, introEndSec: 0, outroStartSec: 0, durationSec: 0, playable: false, at: this.now() }
      if (!this.signal.cancelled) this.cache.put(id, facts)
      return facts
    }).finally(() => { this.waiting--; this.inflight.delete(id) })
    this.chain = job.catch(() => {})
    this.inflight.set(id, job)
    return job
  }

  dispose(): void { this.signal.cancelled = true }
}
```

```ts
// What the listener asked for. The old keyword parser read "no more slow
// songs" as "chill" and "Calm Down by Rema" as a mood, and had nowhere to
// keep "don't play Drake". Here, standing requests become SET RULES the
// planner enforces on every pick; negation is resolved before any mood word
// is read; song titles are recognised before moods; only then do one-shot
// actions fall through to the existing command parser.
import { parseCommand, type DjIntent } from '../djBrain'

export type SetRule =
  | { kind: 'banArtist'; artist: string }
  | { kind: 'onlyGenres'; genres: string[] }
  | { kind: 'moreGenre'; genre: string }
  | { kind: 'lessGenre'; genre: string }
  | { kind: 'tempoRange'; min?: number; max?: number }
  | { kind: 'minEnergy'; level: number; untilMs?: number }
  | { kind: 'maxEnergy'; level: number; untilMs?: number }
  | { kind: 'noExplicit' }
  | { kind: 'stopAfterCurrent' }
  | { kind: 'sequence'; steps: { query: string; count: number }[] }
  | { kind: 'playNext'; query: string }
  | { kind: 'discoveryBurst'; tracks: number }
  | { kind: 'favoritesOnly'; tracks: number }

const NEG = /\b(no|no more|not|don'?t|do not|stop( the)?|without|avoid|less|fewer|enough( of)?|skip the)\b/
const HOUR = 3_600_000
const titleCase = (s: string) => s.replace(/\b\w/g, c => c.toUpperCase())

function strip(t: string): string {
  return t.replace(/^(hey |ok |okay )?(dj|ai dj|aihub)[ ,:]*/, '')
    .replace(/^(can|could|would|will) you (please )?/, '').replace(/^(please|pls|just|now|i want you to|i need you to|let'?s) /, '')
    .replace(/ (please|pls|for me|thanks|thank you)$/, '').trim()

  const m = /for (?:the )?(?:next )?(an?|\d+(?:\.\d+)?) ?(hours?|hrs?|h|minutes?|mins?|m)\b/.exec(t)
  if (!m) return undefined
  const n = m[1] === 'a' || m[1] === 'an' ? 1 : Number(m[1])
  return /^h/.test(m[2]) ? n * HOUR : n * 60_000
}

function rules(t: string, now: number): SetRule | { remove: SetRule['kind']; value?: string } | null {
  let m: RegExpExecArray | null

  // Lifting a ban comes before banning: "you can play Drake again".
  if ((m = /^(?:you can |it'?s ok(?:ay)? to )?play (.+?) again$/.exec(t))) return { remove: 'banArtist', value: m[1].replace(/^any /, '').trim() }

  // Song titles before anything mood-shaped: "play Calm Down by Rema next".
  if ((m = /^(?:play|put on|queue|cue up) "([^"]{2,80})"(?: by ([^,]{2,60}))?(?: next| now)?$/.exec(t))) return { kind: 'playNext', query: [m[1], m[2]].filter(Boolean).join(' ').trim() }
  if ((m = /^(?:play|put on|queue|cue up) (.{2,80}?) by (.{2,60}?)(?: next| now)?$/.exec(t))) return { kind: 'playNext', query: `${m[1]} ${m[2]}`.trim() }

  if (/^stop after (this|the current)( one| song| track)?$|^(this is|make this) the last (song|one|track)$|^last song$/.test(t)) return { kind: 'stopAfterCurrent' }
  if (/\b(explicit|clean versions?|no swearing|no cursing|radio edits?)\b/.test(t) && /\b(no|avoid|without|clean|only|radio)\b/.test(t)) return { kind: 'noExplicit' }

  // Negation resolved BEFORE mood words: "no more slow songs" raises the floor.
  if (NEG.test(t) && SLOW_WORDS.test(t) && !/\b(more|keep|play some)\b.*\bslow\b/.test(t.replace(/no more/, ''))) {
    return { kind: 'minEnergy', level: 0.5, ...(durationMs(t) ? { untilMs: now + durationMs(t)! } : {}) }
  }
  if (/\b(keep|stay|hold)\b.*\b(energy|vibe|it)\b.*\b(high|up|hype)\b|\bhigh energy\b/.test(t)) {
    const d = durationMs(t)
    return { kind: 'minEnergy', level: 0.65, ...(d ? { untilMs: now + d } : {}) }
  }
  if (/\b(keep|stay|hold)\b.*\b(energy|vibe|it)\b.*\b(low|down|chill|calm)\b/.test(t)) {
    const d = durationMs(t)
    return { kind: 'maxEnergy', level: 0.45, ...(d ? { untilMs: now + d } : {}) }
  }

  if ((m = /\b(?:under|below|less than|max(?:imum)?|no faster than) (\d{2,3}) ?bpm\b/.exec(t))) return { kind: 'tempoRange', max: Number(m[1]) }
  if ((m = /\b(?:over|above|more than|at least|min(?:imum)?) (\d{2,3}) ?bpm\b/.exec(t))) return { kind: 'tempoRange', min: Number(m[1]) }
  if ((m = /\bbetween (\d{2,3}) and (\d{2,3}) ?bpm\b/.exec(t))) return { kind: 'tempoRange', min: Math.min(+m[1], +m[2]), max: Math.max(+m[1], +m[2]) }

  const genres = genreIn(t)
  if (genres.length) {
    if (/^(less|fewer|not so much|enough|no more|stop the|stop playing|no) /.test(t)) return { kind: 'lessGenre', genre: genres[0] }
    if (/^(only|play only|just|stick to|stick with|switch to|change to|all|nothing but)\b/.test(t) || /\bonly\b/.test(t)) return { kind: 'onlyGenres', genres }
    if (/^(more|add more|more of|extra)\b/.test(t)) return { kind: 'moreGenre', genre: genres[0] }
  }

  if (/\b(never heard|something new|new (music|songs|stuff)|surprise me with new|discover)\b/.test(t)) return { kind: 'discoveryBurst', tracks: 3 }
  if (/\b(my (favorites|favourites|faves|liked songs|likes)|songs i (love|like))\b/.test(t)) return { kind: 'favoritesOnly', tracks: 5 }

  // Sequences: "play 3 Wizkid songs then Davido".
  if ((m = /^play (\d{1,2}|a few|two|three|four|five) (.+?) (?:songs?|tracks?)?(?: then | and then )(.+)$/.exec(t))) {
    const words: Record<string, number> = { 'a few': 3, two: 2, three: 3, four: 4, five: 5 }
    const count = words[m[1]] ?? Number(m[1])
    const first = m[2].replace(/ (songs?|tracks?)$/, '').trim()
    const second = m[3].replace(/ (songs?|tracks?)$/, '').trim()
    return { kind: 'sequence', steps: [{ query: first, count: Math.min(10, count) }, { query: second, count: 1 }] }
  }

  // Bans: "don't play drake", "no more Drake", "skip the Drake songs".
  if ((m = /^(?:don'?t|do not|never) play (?:any )?(?:more )?(.{2,40}?)(?: songs?| music)?$/.exec(t)) || (m = /^no more (.{2,40}?)(?: songs?| music)?$/.exec(t))) {
    const who = m[1].trim()
    if (!genreIn(who).length && !SLOW_WORDS.test(who)) return { kind: 'banArtist', artist: who }
  }
  return null
}

export function ruleLabel(r: SetRule): string {
  switch (r.kind) {
    case 'banArtist': return `No ${titleCase(r.artist)}`
    case 'onlyGenres': return `Only ${r.genres.map(titleCase).join(' + ')}`
    case 'moreGenre': return `More ${titleCase(r.genre)}`
    case 'lessGenre': return `Less ${titleCase(r.genre)}`
    case 'tempoRange': return r.min && r.max ? `${r.min}–${r.max} BPM` : r.max ? `≤ ${r.max} BPM` : `≥ ${r.min} BPM`
    case 'minEnergy': return r.level >= 0.65 ? 'High energy' : 'No slow songs'
    case 'maxEnergy': return 'Keep it calm'
    case 'noExplicit': return 'Clean versions'
    case 'stopAfterCurrent': return 'Last song'
    case 'sequence': return r.steps.map(s => `${s.count}× ${titleCase(s.query)}`).join(' → ')
    case 'playNext': return `Next: ${titleCase(r.query)}`
    case 'discoveryBurst': return `${r.tracks} new to you`
    case 'favoritesOnly': return `${r.tracks} favourites`
  }
}

function confirmFor(i: Instruction): string {
  if ('rule' in i) {
    const r = i.rule
    switch (r.kind) {
      case 'banArtist': return `Got it — no ${titleCase(r.artist)} for the rest of the set.`
      case 'stopAfterCurrent': return 'Got it — this is the last song.'
      case 'playNext': return `Got it — ${titleCase(r.query)} is up next.`
      case 'sequence': return `Got it — ${ruleLabel(r)}.`
      default: return `Got it — ${ruleLabel(r).toLowerCase()}${'untilMs' in r && r.untilMs ? ' for a while' : ''}.`
    }
  }
  if ('removeRule' in i) return `Okay — ${i.value ? titleCase(i.value) : 'that'} is allowed again.`
  return ''
}

export function parseInstruction(text: string, now = Date.now()): Parsed {
  const t = strip(clean(text))
  if (!t) return { items: [], confirm: '', understood: false }
  const r = rules(t, now)
  if (r && 'remove' in r) {
    const item: Instruction = { removeRule: r.remove, ...(r.value ? { value: r.value } : {}) }
    return { items: [item], confirm: confirmFor(item), understood: true }
  }
  if (r) {
    const item: Instruction = { rule: r }
    return { items: [item], confirm: confirmFor(item), understood: true }
  }
  // "slow songs please" is a positive mood request: chill.
  if (SLOW_WORDS.test(t) && !NEG.test(t)) return { items: [{ action: { type: 'energy', to: 'chill' } }], confirm: 'Bringing it down.', understood: true }
  const a = parseCommand(text)
  if (a) return { items: [{ action: a }], confirm: '', understood: true }
  return { items: [], confirm: "I didn't catch that — try “no Drake”, “only amapiano” or “skip”.", understood: false }
}

// ── Model fallback: only for what the rules cannot read ────────────────────
const RULE_KINDS = new Set(['banArtist', 'onlyGenres', 'moreGenre', 'lessGenre', 'tempoRange', 'minEnergy', 'maxEnergy', 'noExplicit', 'stopAfterCurrent', 'sequence', 'playNext', 'discoveryBurst', 'favoritesOnly'])
const ACTION_TYPES = new Set(['skip', 'pause', 'resume', 'like', 'dislike', 'status'])

export function buildInstructionPrompt(text: string): { role: string; content: string }[] {
  return [
    { role: 'system', content: 'Turn a DJ listener request into JSON: {"rules":[...],"actions":[...]}. Rule kinds: banArtist{artist}, onlyGenres{genres[]}, moreGenre{genre}, lessGenre{genre}, tempoRange{min?,max?}, minEnergy{level 0-1}, maxEnergy{level 0-1}, noExplicit, stopAfterCurrent, sequence{steps[{query,count}]}, playNext{query}, discoveryBurst{tracks}, favoritesOnly{tracks}. Action types: skip, pause, resume, like, dislike, status. Reply with JSON only.' },
    { role: 'user', content: text.slice(0, 400) },
  ]
}

function sanitizeRule(r: any): SetRule | null {
  if (!r || !RULE_KINDS.has(r.kind)) return null
  const s = (v: unknown) => typeof v === 'string' ? v.trim().toLowerCase().slice(0, 60) : ''
  const n = (v: unknown, lo: number, hi: number) => typeof v === 'number' && v >= lo && v <= hi ? v : undefined
  switch (r.kind) {
    case 'banArtist': return s(r.artist) ? { kind: 'banArtist', artist: s(r.artist) } : null
    case 'onlyGenres': return Array.isArray(r.genres) && r.genres.length ? { kind: 'onlyGenres', genres: r.genres.map(s).filter(Boolean).slice(0, 5) } : null
    case 'moreGenre': case 'lessGenre': return s(r.genre) ? { kind: r.kind, genre: s(r.genre) } : null
    case 'tempoRange': { const min = n(r.min, 40, 220), max = n(r.max, 40, 220); return min || max ? { kind: 'tempoRange', ...(min ? { min } : {}), ...(max ? { max } : {}) } : null }
    case 'minEnergy': case 'maxEnergy': { const level = n(r.level, 0, 1); return level !== undefined ? { kind: r.kind, level } : null }
    case 'sequence': return Array.isArray(r.steps) && r.steps.length ? { kind: 'sequence', steps: r.steps.slice(0, 5).map((x: any) => ({ query: s(x?.query), count: n(x?.count, 1, 10) ?? 1 })).filter((x: any) => x.query) } : null
    case 'playNext': return s(r.query) ? { kind: 'playNext', query: s(r.query) } : null
    case 'discoveryBurst': case 'favoritesOnly': return { kind: r.kind, tracks: n(r.tracks, 1, 20) ?? 3 }
    default: return { kind: r.kind } as SetRule
  }
}

export function parseModelInstructions(reply: string, now = Date.now()): Parsed {
  void now
  const m = /\{[\s\S]*\}/.exec(reply || '')
  if (!m) return { items: [], confirm: '', understood: false }
  try {
    const j = JSON.parse(m[0])
    const items: Instruction[] = []
    for (const r of Array.isArray(j.rules) ? j.rules : []) { const ok = sanitizeRule(r); if (ok) items.push({ rule: ok }) }
    for (const a of Array.isArray(j.actions) ? j.actions : []) if (ACTION_TYPES.has(a?.type)) items.push({ action: { type: a.type } as DjIntent })
    return { items, confirm: items.map(confirmFor).filter(Boolean).join(' '), understood: items.length > 0 }
  } catch { return { items: [], confirm: '', understood: false } }
}
```

```ts
  peak:    d => [{ atMin: 0, level: 0.75 }, { atMin: d * 0.5, level: 0.95 }, { atMin: d, level: 0.85 }],
  late:    d => [{ atMin: 0, level: 0.55 }, { atMin: d, level: 0.3 }],
  focus:   d => [{ atMin: 0, level: 0.3 }, { atMin: d, level: 0.3 }],
  workout: d => [{ atMin: 0, level: 0.7 }, { atMin: d * 0.3, level: 0.95 }, { atMin: d * 0.9, level: 0.95 }, { atMin: d, level: 0.6 }],
  default: d => [{ atMin: 0, level: 0.45 }, { atMin: d * 0.65, level: 0.8 }, { atMin: d, level: 0.6 }],
}

export function curveAt(curve: EnergyPoint[], atMin: number): number {
  if (!curve.length) return 0.5
  if (atMin <= curve[0].atMin) return curve[0].level
  for (let i = 1; i < curve.length; i++) {
    const a = curve[i - 1], b = curve[i]
    if (atMin <= b.atMin) return a.level + ((b.level - a.level) * (atMin - a.atMin)) / Math.max(1e-9, b.atMin - a.atMin)
  }
  return curve[curve.length - 1].level
}

function readDuration(t: string): number | null {
  const m = /(\d+(?:\.\d+)?) ?(h|hr|hrs|hour|hours|m|min|mins|minute|minutes)\b/.exec(t)
  if (!m) return null
  const n = Number(m[1])
  return Math.round(/^h/.test(m[2]) ? n * 60 : n)
}

export function parseBrief(text: string, opts: { nowHour?: number; nowMinute?: number; now?: number } = {}): SetBrief {
  const now = new Date()
  const nowHour = opts.nowHour ?? now.getHours(), nowMinute = opts.nowMinute ?? now.getMinutes()
  const lower = text.toLowerCase().trim()
  const durationMin = Math.min(240, Math.max(20, readDuration(lower) ?? 60))

  const shapeKey = /warm[- ]?up|opening/.test(lower) ? 'warmup' : /\bpeak\b|party|hype|club/.test(lower) ? 'peak'
    : /late night|after ?hours|wind down/.test(lower) ? 'late' : /focus|study|work(ing)? music|concentrat/.test(lower) ? 'focus'
    : /workout|gym|run(ning)?|training/.test(lower) ? 'workout' : 'default'
  let curve = SHAPES[shapeKey](durationMin)

  // "peak at 11" / "peak at 23:30": put the top of the curve there.
  const pk = /peak (?:at|around) (\d{1,2})(?::(\d{2}))? ?(am|pm)?/.exec(lower)
  if (pk) {
    let h = Number(pk[1]) % 24
    if (pk[3] === 'pm' && h < 12) h += 12
    else if (!pk[3] && h < 12 && h + 12 > nowHour) h += 12
    const at = ((h * 60 + Number(pk[2] || 0)) - (nowHour * 60 + nowMinute) + 1440) % 1440
    const atMin = Math.min(durationMin, at)
    curve = [{ atMin: 0, level: curve[0].level }, { atMin, level: 0.95 }, ...(atMin < durationMin ? [{ atMin: durationMin, level: 0.75 }] : [])]
  }

  const rules: SetRule[] = []
  const seeds: string[] = []
  const parts = lower.split(/,|;| into | then | and then /).map(s => s.trim()).filter(Boolean)
  for (const part of parts) {
    const asRule = parseInstruction(part, opts.now)
    const r = asRule.items.find(i => 'rule' in i)
    if (r && 'rule' in r && r.rule.kind !== 'onlyGenres' && r.rule.kind !== 'moreGenre') { rules.push(r.rule); continue }
    const seed = part
      .replace(/\b\d+(?:\.\d+)? ?(h|hr|hrs|hours?|m|mins?|minutes?)\b/g, '')
      .replace(/\bpeak (?:at|around) \d{1,2}(?::\d{2})? ?(am|pm)?\b/g, '')
      .replace(/\b(warm[- ]?up|opening|peak hour|peak|party hits|late night|after ?hours|wind down|focus|workout|high energy|set|mix|music|for|a|an|the|of|some)\b/g, '')
      .replace(/\s+/g, ' ').trim()
    if (seed && !/^\d+$/.test(seed)) seeds.push(...seed.split(/ and | & /).map(s => s.trim()).filter(Boolean))
  }

  return { vibe: text.trim(), durationMin, curve, discoveryShare: 0.25, seeds: seeds.length ? seeds : [lower.split(',')[0].trim()], rules }
}
```

```ts
// src/renderer/src/components/dj/ai/setPlanner.ts
// Picks the next song. Pure and deterministic: every number it uses was
// measured or comes from the listener's own history, and every part of the
// score is returned so the stage can say WHY a song was chosen.
import type { DjTrack } from '../engine/DjEngine'
import { trackId, type TrackFacts } from './types'
import type { SetRule } from './instructions'

export interface Candidate { track: DjTrack; facts: TrackFacts | null; known: boolean; taste: number; disliked: boolean; genres: string[] }
export interface PlanContext {
  current: { bpm: number | null; camelot: string | null } | null
  targetEnergy: number
  discoveryShare: number
  played: { id: string; artist: string; atMin: number; known: boolean }[]
  nowMin: number
  rules: SetRule[]
  nowMs: number
}
export interface Scored {
  candidate: Candidate
  total: number
  parts: { tempo: number; key: number; energy: number; taste: number; discovery: number }
  why: string
  transition: 'beatmatch' | 'echo' | 'filter'
}

const W = { tempo: 0.3, key: 0.2, energy: 0.2, taste: 0.2, discovery: 0.1 }
const ARTIST_GAP_MIN = 45
const norm = (s: string) => s.trim().toLowerCase()

export function tempoFit(cur: number | null, bpm: number | null): number {
  if (!cur || !bpm) return 0.5
  const ratios = [bpm / cur, (bpm * 2) / cur, bpm / (cur * 2)]
  const off = Math.min(...ratios.map(r => Math.abs(1 - r)))
  if (off <= 0.03) return 1
  if (off >= 0.08) return 0
  return 1 - (off - 0.03) / 0.05
}

export function keyFit(a: string | null, b: string | null): number {
  if (!a || !b) return 0.5
  const na = Number(a.slice(0, -1)), nb = Number(b.slice(0, -1))
  const d = Math.min((na - nb + 12) % 12, (nb - na + 12) % 12)
  const same = a.slice(-1) === b.slice(-1)
  if ((same && d <= 1) || (!same && d === 0)) return 1
  if (same && d === 2) return 0.5
  return 0.2
}

const active = (r: SetRule, nowMs: number) => !('untilMs' in r && r.untilMs !== undefined && nowMs > r.untilMs)
const EXPLICIT = /\b(explicit|uncensored|dirty)\b/i

export function allowedByRules(c: Candidate, rules: SetRule[], nowMs: number): boolean {
  const artist = norm(c.track.artist)
  const energy = c.facts?.energy ?? 0.5
  for (const r of rules) {
    if (!active(r, nowMs)) continue
    switch (r.kind) {
      case 'banArtist': if (artist.includes(norm(r.artist)) || norm(c.track.title).includes(norm(r.artist))) return false; break
      case 'onlyGenres': if (!c.genres.some(g => r.genres.includes(g))) return false; break
      case 'tempoRange': {
        const bpm = c.facts?.bpm
        if (bpm && ((r.min && bpm < r.min) || (r.max && bpm > r.max))) return false
        break
      }
      case 'minEnergy': if (c.facts && energy < r.level) return false; break
      case 'maxEnergy': if (c.facts && energy > r.level) return false; break
      case 'noExplicit': if (EXPLICIT.test(c.track.title) || EXPLICIT.test(c.track.name)) return false; break
      default: break
    }
  }
  return true
}

function genreBias(c: Candidate, rules: SetRule[]): number {
  let b = 0
  for (const r of rules) {
    if (r.kind === 'moreGenre' && c.genres.includes(r.genre)) b += 0.25
    if (r.kind === 'lessGenre' && c.genres.includes(r.genre)) b -= 0.4
  }
  return b
}

export function rankCandidates(cands: Candidate[], ctx: PlanContext): Scored[] {
  const playedIds = new Set(ctx.played.map(p => p.id))
  const recentArtists = new Set(ctx.played.filter(p => ctx.nowMin - p.atMin < ARTIST_GAP_MIN).map(p => norm(p.artist)))
  const newSoFar = ctx.played.filter(p => !p.known).length
  const wantNew = ctx.played.length ? newSoFar / ctx.played.length < ctx.discoveryShare : ctx.discoveryShare >= 0.5

  const out: Scored[] = []
  for (const c of cands) {
    if (c.disliked || c.facts?.playable === false) continue
    if (playedIds.has(trackId(c.track))) continue
    if (recentArtists.has(norm(c.track.artist))) continue
    if (!allowedByRules(c, ctx.rules, ctx.nowMs)) continue

    const tempo = tempoFit(ctx.current?.bpm ?? null, c.facts?.bpm ?? null)
    const key = keyFit(ctx.current?.camelot ?? null, c.facts?.camelot ?? null)
    const energy = c.facts ? 1 - Math.min(1, Math.abs(c.facts.energy - ctx.targetEnergy) / 0.5) : 0.5
    const taste = (c.taste + 1) / 2
    const discovery = wantNew ? (c.known ? 0 : 1) : (c.known ? 1 : 0.3)
    const total = W.tempo * tempo + W.key * key + W.energy * energy + W.taste * taste + W.discovery * discovery + genreBias(c, ctx.rules)

    const reasons: string[] = []
    if (!c.known) reasons.push('new to you')
    else if (c.taste > 0.4) reasons.push('one of your favourites')
    if (tempo >= 0.9 && key >= 1) reasons.push('same key family, smooth mix')
    else if (tempo >= 0.9) reasons.push('matching tempo')
    else if (key >= 1) reasons.push('compatible key')
    if (c.facts && energy >= 0.8) reasons.push(c.facts.energy > (ctx.current ? ctx.targetEnergy - 0.05 : 0) ? 'keeps the energy where you want it' : 'brings the energy down')

    const bpmKnown = !!c.facts?.bpm && (c.facts?.bpmConfidence ?? 0) >= 0.7 && !!ctx.current?.bpm
    const transition: Scored['transition'] = !bpmKnown ? 'echo' : tempo > 0 ? 'beatmatch' : 'filter'
    out.push({ candidate: c, total, parts: { tempo, key, energy, taste, discovery }, why: reasons.join(' · ') || 'fits the vibe', transition })
  }
  return out.sort((a, b) => b.total - a.total)
}
```

```ts
// Where songs come from: the listener's favourites and most-loved tracks, and
// YouTube searches seeded by the brief (genre seeds are remembered on each
// track so genre rules can be enforced later).
import type { DjTrack } from '../engine/DjEngine'
import type { TasteProfile } from '../taste'
import type { Candidate } from './setPlanner'

export interface PoolDeps { profile(): TasteProfile; favorites(): DjTrack[]; search(q: string, n: number): Promise<DjTrack[]> }

const norm = (s: string) => s.trim().toLowerCase()

export async function gatherCandidates(seeds: string[], deps: PoolDeps, opts: { perSeed?: number; favoritesOnly?: boolean } = {}): Promise<Omit<Candidate, 'facts'>[]> {
  const p = deps.profile()
  const artistScore = new Map(p.topArtists.map(a => [norm(a.artist), a.score]))
  const maxScore = Math.max(1, ...p.topArtists.map(a => a.score))
  const avoid = new Set(p.avoidArtists.map(norm))
  const loved = new Set(p.lovedTracks.map(t => `${norm(t.artist)}|${norm(t.title)}`))
  const out = new Map<string, Omit<Candidate, 'facts'>>()
  const add = (t: DjTrack, genre?: string) => {
    const key = t.youtubeId || t.path
    if (!key) return
    const prev = out.get(key)
    if (prev) { if (genre && !prev.genres.includes(genre)) prev.genres.push(genre); return }
    const a = norm(t.artist)
    const known = loved.has(`${a}|${norm(t.title)}`) || artistScore.has(a)
    out.set(key, { track: t, known, taste: Math.max(-1, Math.min(1, (artistScore.get(a) ?? 0) / maxScore)), disliked: avoid.has(a), genres: genre ? [genre] : [] })
  }
  for (const t of deps.favorites()) add(t)
  if (!opts.favoritesOnly) {
    const per = opts.perSeed ?? 15
    const lists = await Promise.all(seeds.slice(0, 4).map(s => deps.search(s, per).then(l => ({ s, l })).catch(() => ({ s, l: [] as DjTrack[] }))))
    for (const { s, l } of lists) for (const t of l) add(t, norm(s))
  }
  return [...out.values()]
}
```

```ts
// src/renderer/src/components/dj/ai/setConductor.ts
// Runs the set. It keeps three analysed songs ready, answers the AutoMixer's
// `next()` — never with nothing while songs remain, because an empty answer
// switches Automix off (the old "AI take-over: nothing happens" bug) — and
// applies every instruction as a rule the next picks must obey.
import { Emitter, type DjTrack } from '../engine/DjEngine'
import { trackId, type TrackFacts } from './types'
import { curveAt, type SetBrief } from './setBrief'
import { gatherCandidates, type PoolDeps } from './candidatePool'
import { rankCandidates, type Candidate, type PlanContext, type Scored } from './setPlanner'
import { ruleLabel, type Parsed, type SetRule } from './instructions'

export interface ConductorDeps {
  pool: PoolDeps
  analysis: { ensure(t: DjTrack): Promise<TrackFacts>; known(t: DjTrack): TrackFacts | null }
  nowPlaying(): { track: DjTrack; facts: TrackFacts | null } | null
  startMixer(): void
  mixNow(t: DjTrack): void
  now?: () => number
}

export interface ConductorState {
  active: boolean
  paused: boolean
  brief: SetBrief | null
  upNext: Scored[]
  rules: SetRule[]
  message: string
  startedAt: number
  played: PlanContext['played']
  /** The last song handed to the mixer and how it will come in — the transition caption. */
  handoff: Handoff | null
}

export interface Handoff { transition: 'beatmatch' | 'echo' | 'filter'; fromBpm: number | null; toBpm: number | null; fromKey: string | null; toKey: string | null }

export function handoffCaption(h: Handoff): string {
  const style = h.transition === 'beatmatch' ? 'bass swap' : h.transition === 'filter' ? 'filter blend' : 'echo out'
  const bpm = h.fromBpm && h.toBpm ? ` · ${Math.round(h.fromBpm)}→${Math.round(h.toBpm)}` : ''
  const key = h.fromKey && h.toKey ? ` · ${h.fromKey}→${h.toKey}` : ''
  return `${style}${bpm}${key}`
}

const LOOKAHEAD = 3
const SHORTLIST = 5

export class SetConductor extends Emitter {
  state: ConductorState = { active: false, paused: false, brief: null, upNext: [], rules: [], message: '', startedAt: 0, played: [], handoff: null }
  private pool: Omit<Candidate, 'facts'>[] = []
  private energyOffset = 0
  private discovery = 0.25
  private refilling: Promise<void> | null = null
  private stopAfter = false
  private bursts = { discovery: 0, favorites: 0 }
  private seq: { query: string; count: number }[] = []
  private playNextQueue: DjTrack[] = []
  private readonly now: () => number

  constructor(private deps: ConductorDeps) {
    super()
    this.now = deps.now ?? Date.now
  }

  private set(patch: Partial<ConductorState>): void { this.state = { ...this.state, ...patch }; this.emit() }
  private minutesIn(): number { return (this.now() - this.state.startedAt) / 60_000 }

  async start(brief: SetBrief): Promise<void> {
    this.discovery = brief.discoveryShare
    this.energyOffset = 0
    this.stopAfter = false
    this.seq = []; this.playNextQueue = []; this.bursts = { discovery: 0, favorites: 0 }
    this.set({ active: true, paused: false, brief, upNext: [], rules: [...brief.rules], played: [], startedAt: this.now(), message: `Building your set: ${brief.vibe}` })
    this.pool = await gatherCandidates(brief.seeds, this.deps.pool)
    await this.refill()
    this.deps.startMixer()
  }

  stop(): void { this.set({ active: false, upNext: [], message: 'Set finished.' }) }

  private context(): PlanContext {
    const last = this.state.upNext[this.state.upNext.length - 1]
    const playing = this.deps.nowPlaying()
    const cur = last?.candidate.facts ?? (playing ? playing.facts ?? this.deps.analysis.known(playing.track) : null)
    const target = this.state.brief ? curveAt(this.state.brief.curve, this.minutesIn() + 4 * (this.state.upNext.length + 1)) : 0.6
    return {
      current: cur ? { bpm: cur.bpm, camelot: cur.camelot } : null,
      targetEnergy: Math.max(0, Math.min(1, target + this.energyOffset)),
      discoveryShare: this.bursts.discovery > 0 ? 1 : this.discovery,
      played: [...this.state.played, ...this.state.upNext.map(s => ({ id: trackId(s.candidate.track), artist: s.candidate.track.artist, atMin: this.minutesIn(), known: s.candidate.known }))],
      nowMin: this.minutesIn(),
      rules: this.state.rules,
      nowMs: this.now(),
    }
  }

  private withFacts(c: Omit<Candidate, 'facts'>): Candidate { return { ...c, facts: this.deps.analysis.known(c.track) } }

  refill(): Promise<void> {
    if (this.refilling) return this.refilling
    this.refilling = this.doRefill().finally(() => { this.refilling = null })
    return this.refilling
  }

  private async doRefill(): Promise<void> {
    if (!this.state.active || this.state.paused) return
    // Requested songs and sequences first: they are instructions, not suggestions.
    while (this.playNextQueue.length && this.state.upNext.length < LOOKAHEAD + 1) {
      const t = this.playNextQueue.shift()!
      const facts = await this.deps.analysis.ensure(t).catch(() => null)
      if (facts && !facts.playable) continue
      this.set({ upNext: [{ candidate: { track: t, facts, known: true, taste: 0, disliked: false, genres: [] }, total: 99, parts: { tempo: 0.5, key: 0.5, energy: 0.5, taste: 0.5, discovery: 0.5 }, why: 'you asked for it', transition: facts?.bpm ? 'beatmatch' : 'echo' }, ...this.state.upNext] })
    }
    let relaxed = false
    while (this.state.upNext.length < LOOKAHEAD) {
      if (this.seq.length) {
        const step = this.seq[0]
        const found = (await this.deps.pool.search(step.query, 8).catch(() => [])).find(t => !this.context().played.some(p => p.id === trackId(t)))
        if (found) {
          step.count--; if (step.count <= 0) this.seq.shift()
          const facts = await this.deps.analysis.ensure(found).catch(() => null)
          this.set({ upNext: [...this.state.upNext, { candidate: { track: found, facts, known: false, taste: 0, disliked: false, genres: [] }, total: 50, parts: { tempo: 0.5, key: 0.5, energy: 0.5, taste: 0.5, discovery: 0.5 }, why: `your request: ${step.query}`, transition: 'echo' }] })
          continue
        }
        this.seq.shift()
      }
      const ctx = this.context()
      let pool = this.pool.map(c => this.withFacts(c))
      if (this.bursts.favorites > 0) pool = pool.filter(c => c.known)
      let ranked = rankCandidates(pool, ctx)
      if (!ranked.length) {
        // Rules filtered everything: widen the pool once, then relax limits.
        const more = await gatherCandidates([...(this.state.brief?.seeds ?? []), ...this.relatedSeeds()], this.deps.pool, { perSeed: 25 })
        this.pool = mergePools(this.pool, more)
        ranked = rankCandidates(this.pool.map(c => this.withFacts(c)), ctx)
        if (!ranked.length) {
          ranked = rankCandidates(this.pool.map(c => this.withFacts(c)), { ...ctx, rules: ctx.rules.filter(r => r.kind === 'banArtist' || r.kind === 'noExplicit') })
          relaxed = ranked.length > 0
        }
        if (!ranked.length) break
      }
      // Measure the shortlist (cached ones are instant), then re-rank on real facts.
      for (const s of ranked.slice(0, SHORTLIST)) if (!s.candidate.facts) await this.deps.analysis.ensure(s.candidate.track).catch(() => null)
      const reranked = rankCandidates(ranked.slice(0, SHORTLIST).map(s => this.withFacts(s.candidate)), relaxed ? { ...ctx, rules: ctx.rules.filter(r => r.kind === 'banArtist' || r.kind === 'noExplicit') } : ctx)
      const pick = reranked[0] ?? ranked[0]
      if (!pick) break
      this.set({ upNext: [...this.state.upNext, pick] })
    }
    if (relaxed) this.set({ message: "Couldn't find songs that fit every rule — I relaxed the tempo/energy limits to keep the music going." })
  }

  private relatedSeeds(): string[] {
    const p = this.deps.pool.profile()
    return [...p.nowArtists.slice(0, 2), ...p.topArtists.slice(0, 2).map(a => a.artist)]
  }

  /** The AutoMixer's hook. Synchronous; never empty while songs remain. */
  next(): DjTrack | undefined {
    if (!this.state.active) return undefined
    if (this.stopAfter) { this.stop(); return undefined }
    let head = this.state.upNext[0]
    if (!head) {
      // Still analysing: hand over the best un-analysed song (safe transition)
      // rather than nothing, which would switch Automix off.
      const ranked = rankCandidates(this.pool.map(c => this.withFacts(c)), this.context())
      head = ranked[0]
      if (!head) return undefined
    } else {
      this.set({ upNext: this.state.upNext.slice(1) })
    }
    const from = this.deps.nowPlaying()
    const fromFacts = from ? from.facts ?? this.deps.analysis.known(from.track) : null
    const to = head.candidate.facts
    this.set({ handoff: { transition: head.transition, fromBpm: fromFacts?.bpm ?? null, toBpm: to?.bpm ?? null, fromKey: fromFacts?.camelot ?? null, toKey: to?.camelot ?? null } })
    this.noteStarted(head.candidate.track, head.candidate.known)
    if (this.bursts.discovery > 0 && !head.candidate.known) this.bursts.discovery--
    if (this.bursts.favorites > 0 && head.candidate.known) this.bursts.favorites--
    void this.refill()
    return head.candidate.track
  }

  noteStarted(t: DjTrack, known = true): void {
    const id = trackId(t)
    if (this.state.played.some(p => p.id === id)) return
    this.set({ played: [...this.state.played, { id, artist: t.artist, atMin: this.minutesIn(), known }] })
  }

  instruct(p: Parsed): void {
    let rules = [...this.state.rules]
    for (const item of p.items) {
      if ('removeRule' in item) {
        rules = rules.filter(r => !(r.kind === item.removeRule && (!item.value || JSON.stringify(r).toLowerCase().includes(item.value.toLowerCase()))))
        continue
      }
      if (!('rule' in item)) continue
      const r = item.rule
      switch (r.kind) {
        case 'stopAfterCurrent': this.stopAfter = true; break
        case 'playNext': void this.deps.pool.search(r.query, 1).then(l => { if (l[0]) { this.playNextQueue.push(l[0]); this.set({ upNext: [] }); void this.refill() } }); break
        case 'sequence': this.seq = r.steps.map(s => ({ ...s })); this.set({ upNext: [] }); break
        case 'discoveryBurst': this.bursts.discovery = r.tracks; this.set({ upNext: [] }); break
        case 'favoritesOnly': this.bursts.favorites = r.tracks; this.set({ upNext: [] }); break
        case 'onlyGenres':
          rules = rules.filter(x => x.kind !== 'onlyGenres'); rules.push(r)
          void gatherCandidates(r.genres, this.deps.pool).then(more => { this.pool = mergePools(this.pool, more); void this.refill() })
          break
        default: rules = rules.filter(x => JSON.stringify(x) !== JSON.stringify(r)); rules.push(r)
      }
    }
    // Drop queued picks that break the new rules; keep the rest.
    const ctxRules = rules
    const keep = this.state.upNext.filter(s => rankCandidates([s.candidate], { ...this.context(), rules: ctxRules, played: [] }).length > 0 || s.why === 'you asked for it')
    this.set({ rules, upNext: keep, message: p.confirm || this.state.message })
    void this.refill()
  }

  removeRule(index: number): void {
    const r = this.state.rules[index]
    if (!r) return
    this.set({ rules: this.state.rules.filter((_, i) => i !== index), message: `Removed: ${ruleLabel(r)}` })
    void this.refill()
  }

  skip(): void {
    const t = this.next()
    if (t) this.deps.mixNow(t)
  }

  steer(s: 'more-energy' | 'calmer' | 'more-like-this'): void {
    if (s === 'more-energy') this.energyOffset = Math.min(0.4, this.energyOffset + 0.15)
    if (s === 'calmer') this.energyOffset = Math.max(-0.4, this.energyOffset - 0.15)
    if (s === 'more-like-this') {
      const p = this.deps.nowPlaying()
      if (p) void gatherCandidates([p.track.artist], this.deps.pool, { perSeed: 10 }).then(more => { this.pool = mergePools(this.pool, more); this.set({ upNext: [] }); void this.refill() })
    }
    this.set({ upNext: [], message: s === 'more-energy' ? 'Lifting the energy.' : s === 'calmer' ? 'Bringing it down.' : 'More like this coming up.' })
    void this.refill()
  }

  setDiscovery(share: number): void { this.discovery = Math.max(0, Math.min(1, share)); this.set({ upNext: [] }); void this.refill() }

  /** "I want the peak at 22:30": dragging the graph moves the top of the curve. */
  setPeak(atMin: number): void {
    const b = this.state.brief
    if (!b) return
    const at = Math.max(0, Math.min(b.durationMin, atMin))
    const start = curveAt(b.curve, 0)
    const curve = [{ atMin: 0, level: at === 0 ? 0.95 : start }, ...(at > 0 ? [{ atMin: at, level: 0.95 }] : []), ...(at < b.durationMin ? [{ atMin: b.durationMin, level: 0.7 }] : [])]
    this.set({ brief: { ...b, curve }, upNext: [], message: `Peak moved to ${Math.round(at)} min in.` })
    void this.refill()
  }

  setPaused(p: boolean): void {
    if (p === this.state.paused) return
    // Coming back from the console: whatever is actually playing is the new
    // starting point, so the old lookahead is stale.
    this.set({ paused: p, ...(p ? {} : { upNext: [] }) })
    if (!p) { const now = this.deps.nowPlaying(); if (now) this.noteStarted(now.track); void this.refill() }
  }
}

function mergePools(a: Omit<Candidate, 'facts'>[], b: Omit<Candidate, 'facts'>[]): Omit<Candidate, 'facts'>[] {
  const out = new Map(a.map(c => [c.track.youtubeId || c.track.path, c]))
  for (const c of b) {
    const k = c.track.youtubeId || c.track.path
    const prev = out.get(k)
    if (!prev) out.set(k, c)
    else for (const g of c.genres) if (!prev.genres.includes(g)) prev.genres.push(g)
  }
  return [...out.values()]
}
```

```tsx
// src/renderer/src/components/dj/stage/EnergyGraph.tsx
import React from 'react'
import { curveAt, type SetBrief } from '../ai/setBrief'

// Click or drag on the graph to move the peak there: the set re-plans.
export default function EnergyGraph({ brief, startedAt, onPeak }: { brief: SetBrief; startedAt: number; played: number; onPeak?: (atMin: number) => void }) {
  const W = 1000, H = 90, steps = 60
  const nowMin = startedAt ? (Date.now() - startedAt) / 60_000 : 0
  const pts = Array.from({ length: steps + 1 }, (_, i) => { const m = (i / steps) * brief.durationMin; return `${(i / steps) * W},${H - curveAt(brief.curve, m) * (H - 10) - 5}` })
  const x = Math.min(W, (nowMin / brief.durationMin) * W)
  const pick = (e: React.PointerEvent<SVGSVGElement>) => {
    if (!onPeak || (e.type === 'pointermove' && e.buttons !== 1)) return
    const r = e.currentTarget.getBoundingClientRect()
    onPeak(Math.max(0, Math.min(1, (e.clientX - r.left) / Math.max(1, r.width))) * brief.durationMin)
  }
  return <svg className="dj-energy" viewBox={`0 0 ${W} ${H}`} preserveAspectRatio="none" role="slider" aria-label="Energy plan — click to move the peak" aria-valuemin={0} aria-valuemax={brief.durationMin} aria-valuenow={Math.round(nowMin)} onPointerDown={pick} onPointerMove={pick}>
    <polyline className="planned" points={pts.join(' ')} />
    <polyline className="played" points={pts.filter((_, i) => (i / steps) * W <= x).join(' ')} />
    <circle className="here" cx={x} cy={H - curveAt(brief.curve, nowMin) * (H - 10) - 5} r="5" />
  </svg>
}
```

```tsx
import React, { useEffect, useRef, useSyncExternalStore } from 'react'
import type { DjEngine } from '../engine/DjEngine'
import VideoMonitor from '../VideoMonitor'

export default function Backdrop({ engine }: { engine: DjEngine }) {
  useSyncExternalStore(engine.subscribe, engine.getVersion)
  const hasVideo = !!(engine.decks.A.track?.youtubeId || engine.decks.B.track?.youtubeId)
  const glow = useRef<HTMLDivElement>(null)
  useEffect(() => {
    let raf = 0
    const tick = () => {
      if (!document.hidden && glow.current) {
        const db = (engine as any).meterDb?.() ?? -60
        const level = Math.max(0, Math.min(1, (db + 40) / 40))
        glow.current.style.setProperty('--level', level.toFixed(3))
      }
      raf = requestAnimationFrame(tick)
    }
    raf = requestAnimationFrame(tick)
    return () => cancelAnimationFrame(raf)
  }, [engine])
  return <div className="dj-backdrop">
    {hasVideo ? <div className="dj-backdrop-video"><VideoMonitor engine={engine} big /></div> : null}
    <div ref={glow} className="dj-backdrop-glow" />
```

```ts
// One door for everything typed or said to the DJ: rules first (instant,
// never inverted), then the existing actions, and the model only for what
// neither understands — and then only in the whitelisted rule format.
import type { DjIntent } from '../djBrain'
import { buildInstructionPrompt, parseInstruction, parseModelInstructions, type Parsed } from '../ai/instructions'

export async function askDj(text: string, deps: { conductor: { instruct(p: Parsed): void }; runAction: (a: DjIntent) => void; chat?: (m: any[]) => Promise<any>; say: (m: string) => void }): Promise<void> {
  let p = parseInstruction(text)
  if (!p.understood && deps.chat) {
    try {
      const res = await deps.chat(buildInstructionPrompt(text))
      if (res?.content && res.provider !== 'none') p = parseModelInstructions(String(res.content))
    } catch { /* fall through to "didn't catch" */ }
  }
  if (!p.understood) { deps.say(parseInstruction(text).confirm || "I didn't catch that."); return }
  const rules = p.items.filter(i => !('action' in i))
  if (rules.length) deps.conductor.instruct({ ...p, items: rules })
  for (const i of p.items) if ('action' in i) deps.runAction(i.action)
  if (!rules.length && p.confirm) deps.say(p.confirm)
}
```

```js
// Live AI DJ check in the built app (isolated profile):
//  1. instructions: typed requests produce the right confirmation and chips
//  2. a set plays: >= 3 tracks, >= 2 transitions, no silence > 2 s

// Usage: npx electron-vite build && node scripts/test-ai-dj-e2e.cjs [minutes=20]
const path = require('path'), os = require('os'), fs = require('fs')
const { _electron } = require(path.join(os.homedir(), 'node_modules', 'playwright-core'))
const REPO = path.resolve(__dirname, '..')
const MINUTES = Number(process.argv[2] || 20)

;(async () => {
  const home = fs.mkdtempSync(path.join(os.tmpdir(), 'ai-dj-e2e-'))
  const env = { ...process.env, USERPROFILE: home, HOME: home }; delete env.ELECTRON_RUN_AS_NODE

  const page = await app.firstWindow()
  await page.waitForTimeout(8000)

  await page.waitForSelector('input[aria-label="Tell the DJ"]', { timeout: 60000 })

  const chips = await page.locator('.dj-rule').allInnerTexts()
  const msg = await page.locator('.dj-stage-message').innerText().catch(() => '')

  const titles = new Set(); let silentSince = 0, longestSilence = 0, transitions = 0, lastTitle = ''
  const end = Date.now() + MINUTES * 60_000
  while (Date.now() < end) {

    if (s.title && s.title !== lastTitle) { if (lastTitle) transitions++; titles.add(s.title); lastTitle = s.title }
```
