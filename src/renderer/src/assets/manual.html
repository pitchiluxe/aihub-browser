What AIHub Browser is

AIHub Browser is a Chromium-based desktop browser with an AI agent wired into its core. It browses the web like Chrome, organizes knowledge like Obsidian, and acts on your behalf like an assistant that can actually click things.

It runs on Windows, macOS, and Linux, built on Electron and Chromium — so every site that works in Chrome works here, including Google sign-in.

Agentic

The AI can open tabs, read pages, fill forms, search the live web, write files, and build whole projects — with your approval at every risky step.

Visual

Bookmarks live in a force-directed constellation you can fly through, search, and replay as a timelapse.

Private

Local AI via Ollama, a free built-in VPN, encrypted tokens, and keys that never leave your machine.

The interface, labeled

Four zones. Learn these and everything else is discoverable.

1 · Tab strip

Drag to reorder, drag out to detach into its own window, right-click for the full tab menu. Scrolls horizontally when full; the active tab always stays visible.

2 · Navigation + address bar

Back, forward, reload, home, then the omnibox. On the right: bookmark, annotate, screenshot, record, the gold Coach button (charts only), and the AI button.

3 · Sidebar

Toggle with the panel icon. Home, Research, Agent Mode, Sticky Notes, History, Downloads, Extensions, Wi-Fi, VPN, Mail, Settings.

4 · AI panel

Docked on the right, resizes the page rather than covering it. Chat, quick actions, and live agent step tracking.

Your first five minutes

This really is a sequence — do it in order and the rest of the app makes sense.

  1. Connect an AI brain. Sidebar → Settings → AI. Paste an OpenRouter key for cloud models (Claude, GPT, Gemini, DeepSeek, Grok, Mistral), or install Ollama and pick a local model for fully private AI. The header of the AI panel tells you which one is live.
  2. Open the assistant. Press Ctrl+Shift+A and ask it something real: research the best budget laptops and give me a table.
  3. Bookmark a few pages. Press Ctrl+D on any site. The AI auto-categorizes and colors each one.
  4. Open the Sphere. Sidebar → Home → sphere view. Hit Timelapse and watch your graph build itself.
  5. Make it yours. Settings → Appearance for 25 themes, transparency, and window opacity.
  6. Try the Trading Coach. Open a TradingView chart (e.g. tradingview.com/chart/?symbol=OANDA:XAUUSD) — a gold Coach button appears. Click it to get a structured gold/Nasdaq analysis of what's on your screen. See Trading Coach.

Split view, vertical tabs & moving tabs home

Two pages at once, a tab strip that survives forty tabs, and a way back from a detached window.

Split view — two pages, one window

Open the command palette with Ctrl+K and run Split view. The active tab takes the left pane and the next tab takes the right. Both are live: scroll, click and type in either. Run it again to go back to one pane.

In the vertical rail, the ⊟ button on any tab row puts that specific tab beside the current one — handy for keeping docs next to the thing you are building.

Vertical tabs & groups

Past roughly a dozen tabs, a horizontal strip turns titles into a memory test. Switch to the left rail in Settings → Startup → Tab strip → Left, and every tab keeps a readable title however many are open.

The layers button at the top of the rail groups the open tabs by site in one click. Group headers fold away, so ten GitHub tabs collapse to a single line until you need them. Groups only form for sites with at least two tabs — a group of one hides nothing and only makes the list longer.

The AI assistant

It remembers now. The conversation is kept between launches, so yesterday’s answers are still there when you reopen the panel. Clear chat wipes it from disk as well as the screen. In a long conversation the oldest turns are condensed to a line each rather than dropped — without that, the assistant’s own instructions are the first thing a local model forgets.
It can search what you have read. Ask “what was that article about renderer crashes?” or “the page I read yesterday about pricing” and it searches your own Rewind archive by meaning — on this machine, with your local model — then answers with a link to the page. The web cannot answer that question; only your browser knows what you read.

This is the part that makes AIHub different from every other browser. It is not a chatbot bolted onto a sidebar — it can act.

Open it with Ctrl+Shift+A or the violet AI button. The header shows which brain is answering: ● Local · Ollama or ● Cloud · OpenRouter.

Three ways to give it context

  • Select text, then right-click → Ask AI about "…" — pre-fills the question with your selection.
  • Attach Page — the quick-action button loads the whole page into the conversation so you can interrogate it.
  • Summarize — one click; afterwards you can export the summary as .md or save it to Articles.
Safety rails you should know about. The agent asks permission before running any shell command, and it will never click a final Submit / Apply / Send button on its own — it stops, shows you exactly what's about to be sent, and waits for your confirmation. If a site needs a login, a CAPTCHA, or a file upload, it hands control back to you. Press the ■ stop button any time to halt a running task.
Getting better answers: say the output shape you want ("as a table", "5 bullets", "a bash script"), name the constraint ("under $500", "published this year"), and tell it when to use real sources ("with citations"). It will use live web search whenever the question needs current facts.

Trading Coach

A dedicated trading analyst that reads your live chart and answers with structured, actionable analysis — only when you're on a TradingView chart.

It reads the live chart first. Every answer starts by reading what's actually on the chart right now — price, levels, trend, structure — before it speaks. The analysis is grounded in reality, not a training cutoff.

How to open it

Navigate to any TradingView chart (e.g. tradingview.com/chart/…). A gold Coach button appears automatically in the navigation bar, next to the AI button. Click it to open the panel. The chart slides left to stay fully visible alongside it.

What it knows

Gold (XAUUSD)

Deep expertise in gold futures and spot. Knows the macro drivers, the key levels, and how gold reacts to FOMC, CPI, and geopolitical events.

Nasdaq (NQ)

Earnings reaction analysis, sector rotation, and FOMC rate sensitivity. Covers the tech-heavy index with precision.

The command palette

Press Ctrl+K anywhere. Start typing and results filter live across five groups:

  • Actions — new tab, reopen closed tab, toggle the AI, annotate, read aloud, find in page, add to Sphere, compare two pages.
  • Go to — every built-in page: Research, Agent, Notes, Rewind, Watch & Ping, History, Downloads, Extensions, Wi-Fi, VPN, Mail, Manual, Settings.
  • Tabs — jump straight to any open tab by title.
  • Bookmarks — open anything in your Sphere.
  • Search / open — if nothing matches, Enter treats what you typed as a URL or a web search.
Everything is keyboard-first: ↑/↓ to move, Enter to run, Esc to close.

Rewind — search what you’ve read

Open Rewind from the sidebar (or the command palette). It keeps a private, on-device index of the pages you genuinely spent time reading — after a few seconds of dwell, the page’s text is captured. Nothing leaves your machine.

Type a phrase you half-remember and Rewind ranks matches by how well the words fit, weighting titles and recent visits, and shows a snippet with your terms highlighted. Click a result to reopen the page. Remove single entries or clear the whole index from the same screen.

Rewind only captures real reading — quick redirects and pages under a sentence or two are skipped, so the index stays useful.

Watch & Ping

Let a page tell you when it changes, instead of you checking it fifty times.

Open Watch & Ping from the sidebar, hit New watch, and paste the page URL. Choose what counts as news:

  • When it changes at all — AIHub fingerprints the page’s text and pings you if anything meaningful shifts.
  • When a word appears — give it a phrase like In stock, Sold, or Closed, and it only pings when that phrase shows up.

Pick how often to re-check — every 15 minutes up to once a day — and AIHub keeps checking quietly in the background, even while you browse elsewhere. When it fires, you get a real desktop notification; click it to jump straight to the page.

The downloads menu new

Everything this browser has pulled down, without leaving the page that produced it.

There is a download arrow in the toolbar, sitting between the bookmarks list and the camera. It carries a small badge counting transfers still in flight, and the icon bobs while something is arriving.

Click it for the whole history: what the file is, a live progress bar, its size, whether it finished, and how long ago. Anything completed gets Open and a folder button; double-clicking the row opens it too. Clear empties the list without touching the files on disk.

The badge only appears when something is actually downloading. A badge that is always lit stops meaning anything.

The full Downloads page is still there for a long history — this is the glance.

Page Vault new

A bookmark is a promise the internet does not keep. This is the browser keeping it anyway.

Pages get rewritten, moved behind a paywall, quietly edited, or deleted outright — and your bookmark is left pointing at a 404. So when you bookmark a page, AIHub also keeps a copy of it, as a single file, on your machine.

You will usually meet this without going looking for it. When a page fails to load and there is a copy of that exact address, a bar appears above the page:

This page didn’t load — but you kept a copy. Click Open the copy and the archived page comes back with its layout, images and links intact.

Open Page Vault in the sidebar to see everything saved. Copies of the same page are grouped together, so a page that changed shows up as more than one row and you can open either. Each row offers Open copy, a folder button to find the file, and a bin to delete it.

QuestionAnswer
What is saved?One .mhtml file per snapshot — the whole page in a single file, under ~/.aihub-browser/vault
When?When you bookmark a page. The same page is not re-archived more than once every 12 hours
How much space?Up to 3 copies per page and 750 MB overall; the oldest are dropped past that
Does it slow bookmarking down?No — it happens quietly afterwards, and a page that refuses to be saved never turns a bookmark into an error
Deleting a saved copy does not delete the bookmark, and clearing the vault never touches your sphere.

PDFs new

Papers, invoices, contracts and manuals stay inside the browser now.

A link to a PDF used to download the file and leave the tab sitting there — the document left the browser, and with it every clever thing AIHub can do to a page. Now PDFs open in the tab, with the full reader: page thumbnails, zoom, search and print.

More usefully, the assistant can read them. Everything that works on a web page works on a PDF, because they all ask for the page’s text and the text now arrives:

  • Ask the AI to summarise or explain the document
  • Read it aloud
  • Clip it to Obsidian
  • Let an agent read it with read_page
A scanned PDF is a picture of some words, not words. AIHub will tell you that plainly rather than showing you an empty summary — and it will say so too if a file is encrypted.

Recall new

Reading two hundred articles and remembering none of them is the normal outcome. This is the fix.

Select any text on any page, right-click, and choose Remember This (Recall). It joins a review queue and comes back to you on a schedule until you actually know it.

Open Recall in the sidebar. The card shows the cue and hides the answer until you press Show me — a review that shows you the answer first is just reading with extra steps. Then say whether you knew it:

AnswerWhat happens

The Everything tab lists all of it, best-known first, with the source page one click away. This is the same scheduler the Bible Lab uses for verses — a highlight and a verse are treated exactly alike.

Highlighting the same passage twice does not reset its schedule. Saying “this matters” a second time should not cost you the progress you made on it.

Morning Brief new

One page for everything that happened while you were away.

Watch knows which pages changed overnight. Your calendar knows what is coming. Your mailbox knows what is unanswered. Recall knows what is due. Each of them needs you to go and look, so in practice none of them get looked at.

Morning Brief in the sidebar puts them on one page, with the calendar first — it is the only part with a deadline attached. Anything happening within the hour is marked; everything else can wait until later in the day. Click any line to go straight there.

Sections with nothing in them are left out entirely, and a genuinely quiet morning says so in one line. Anything you have not connected — a calendar, a mailbox — simply contributes nothing instead of turning the page into an error message.

Ledger new

What you actually spent, assembled from receipts you were already sent.

Purchase confirmations arrive as email. Their invoices arrive as PDFs in your downloads folder. Nothing ever puts the two together, so working out last month’s spending means searching your mail badly and retyping numbers into a spreadsheet.

Open Ledger in the sidebar, choose a window — last month up to last year — and press Read receipts. AIHub reads purchase mail from your own mailbox and builds the table: date, merchant, amount, currency. It totals each currency separately, flags what looks like a subscription, and exports the whole thing as CSV.

If an invoice PDF in your Downloads mentions the same merchant, the row offers a link to open it.

Tables to CSV new

Stop copying web tables into spreadsheets by hand.

Press Ctrl+K and choose Export a table from this page to CSV. AIHub lists every real table on the page — with its name, its size, and its first row so you can tell them apart — and writes the one you pick.

It handles the things that make hand-copying wrong:

  • Merged cells are expanded, so a header spanning two columns does not shift everything underneath it
  • Invisible spaces inside numbers are converted, so amounts import as numbers instead of text
  • Layout tables — the single-column ones older sites use for positioning — are left out of the list
  • Cells that look like formulas are defused, so opening the file cannot run something the page wrote

Credential guard new

A second look before you type a password somewhere you have never typed one.

Phishing works because a domain that is wrong by one character looks right when you are reading quickly. Blocklists answer that by knowing which sites are bad, which means they are always behind whoever registered a domain this morning.

AIHub asks a different question: does this look like one of yours, without being it? It compares the site against the ones you actually use, from your own history. When a page asks for a password and something is off, a bar appears:

What you seeWhat it means
Check this address before signing inThe domain closely resembles a site you really use, or is written in an encoded alphabet
First time signing in hereNothing suspicious — just a site you have never signed into before
It never blocks anything, and it never reads, stores or sends what you type. The check is on the address only. On a brand-new profile it stays quiet entirely, because it has no idea yet which sites are yours.

Burner tabs & sharing new

A tab that forgets, and a fast way to pass something to the Lounge.

Press Ctrl+K and choose Open a burner tab. It gets a session of its own that is never written to disk: cookies, storage and any sign-in you do inside it exist for as long as the tab does and are gone when you close it. Every burner gets its own session, so two of them cannot see each other.

See Sessions & containers for the persistent version — containers keep their cookies on purpose, so you can be signed into the same site as two different people.

Separately: select some text, right-click, and pick Share to the Lounge to post the passage and its source into Community. Nothing is ever posted unless you choose that menu item.

Bible

The whole Bible, bundled into the app and rendered as a real book you turn with your hand — no internet connection required.

Open Bible from the sidebar or the command palette (Ctrl+K). All 66 books are built into AIHub itself, so the reader opens and reads even with no network connection at all.

The text is the World English Bible (WEB), a modern-English translation that is fully public domain — free of the licensing that covers translations like the NIV, NKJV, or ESV.

Opening the book

The Bible starts closed, as a bound volume with gilt page edges and a ribbon marker. Click the cover (or press Enter) and it swings open on its spine. If you have read before, the cover tells you where you left off — Continue — John 3 — and opens straight back to that spread. Your place is remembered between sessions automatically.

Sharing a verse

The share sheet offers Facebook, X, WhatsApp, LinkedIn, Telegram, Reddit, and Email — each opens the platform in your system browser with the verse and its reference pre-filled. Copy puts the quote and reference on your clipboard.

TikTok and Instagram don't accept a shared link at all, so they're not in that row. Use Save image instead — it renders the verse onto a shareable image and downloads it as a PNG, ready for you to post yourself.

Study with AI

Press Ask in the reader's header and a study panel opens beside the book. Ask it anything — “find verses about money”, “what does the Bible say about forgiveness?”, “give me a verse for when I feel afraid” — and it answers like a patient teacher, in plain language.

The important part is where its answers come from. The first time you open the panel, AIHub reads all 31,103 verses and builds a search index on your machine. Every question is then answered from verses it actually finds in that text, and those verses are handed to the AI as the only scripture it is allowed to quote. It is explicitly forbidden to recall a verse from memory or invent a reference — the failure that would make a Bible app worthless.

Searching is done in scripture's own vocabulary, not just your words. Ask about “money” and it also looks for mammon, riches, treasure, covet; say “I feel afraid” and it reaches for fear, dread, courage, dismayed. That is the difference between being handed a ledger entry in Kings and being handed the Sermon on the Mount.

The panel uses whichever AI you have set up in Settings — Ollama running locally (private, nothing leaves your machine) or an OpenRouter key. With no AI configured the reader still works completely; only the Ask panel needs one.
It will tell you when the text doesn't answer your question rather than filling the gap with a guess, and on contested questions it gives the main views fairly instead of ruling. It isn't a substitute for a real pastor or counsellor, and it will say so.

A handful of verses look empty

Luke 17:36, Acts 8:37, Acts 15:34, Acts 24:7, and Romans 16:25 show a small italic note instead of verse text. The WEB keeps these traditional verse numbers even though the passages themselves are absent from the oldest manuscripts — most modern translations quietly renumber around them. It's expected, not a bug.

Community

Rooms inside the browser where people using AIHub meet and talk — text channels, voice channels, and screen sharing, under a name you pick, with no email and no password anywhere.

Open Community from the sidebar. The first time, you are asked for one thing: a name. There is no email field, no password, no account to recover — this machine generates a key, that key is your membership, and nothing else about you is stored.

Choosing a name

Names are unique across the whole community, so the field checks availability as you type. The avatar beside it is generated from the name itself — you cannot upload a picture, and nobody else can either. If the name you want is gone, the field offers alternatives you can click.

Uniqueness ignores capitals and character width, so Grace, grace and GRACE are one name, not three. That is deliberate: a room where two people can both be "Grace" is a room where you cannot tell who said what.

Channels are grouped down the left-hand side. Every text room opens with a short message saying what belongs there and asking something you can answer, so you never arrive at a blank screen.

Talking

Enter sends, Shift+Enter starts a new line. Reply to a message to quote it, or open it as a thread when a side conversation deserves its own space. Reactions, mentions and direct messages all work as you would expect.

Some rooms accept more than plain text. Bible Study takes verses shared straight from the Bible reader — they arrive as a card anyone can open and read in full — along with prayer requests and testimony. The developer rooms take code, syntax highlighted, and never executed by anyone who reads it.

A prayer request can be posted anonymously: your name is hidden from the room, though the request itself is still public. Nothing in a community room is private.

Voice rooms

Click Lounge or Workshop to drop in. A dock appears along the bottom with your microphone, headphones, camera and screen share.

The room makes a small sound when somebody arrives or leaves — two notes rising for an arrival, falling for a departure — so you can tell who came and went while you are looking at something else. The bell in the dock turns that off, and the choice is remembered on this machine.

Files

Images, video and PDFs can be attached to a message. They are checked by their actual contents rather than by their file name, and they are stored in your own profile folder — nothing is uploaded to a server anywhere.

Keeping the rooms civil

Every message has a Report button. Reports go to a queue the community owner reviews, and enough reports on one message hides it pending that review. Blocking somebody hides everything they have said, including what they said before you blocked them, and it is reversible — nothing is destroyed.

Owners get more: timing somebody out for an afternoon, banning them outright, removing a message, and a role system for handing out moderator powers.

The community guide

The guide is an optional AI that runs on the community owner's machine only, through Ollama. It is switched off until the owner turns it on, and it does exactly two things:

It writes into quiet rooms

When a channel has had nothing in it for hours, the guide posts one short thing to talk about — at most twice a day, and never while a conversation is happening.

It reports, it never removes

It reads new messages and files anything concerning into the moderation queue with its reasoning attached. It cannot hide, delete or ban. A person decides.

It has no internet access: everything it writes comes from the model's own knowledge and the room's recent messages, so it cannot bring an article, a link or a statistic in from outside. Every message it writes carries an AI badge beside the name, every time.

Because the guide runs on one machine through that machine's Ollama, it needs a model chosen in its panel before it will do anything. If it says it is not running, the panel names the reason.

On this computer, or shared

Out of the box the community is local: everything you post stays on your machine and nobody else can see it, which the banner at the top says plainly. It becomes a real shared community when a backend is connected — a Supabase project, entered once in the setup panel — at which point your name, your key and everything already written carry over.

Your identity, and leaving

Your account in the rail holds the key this machine generated. Export it and import it on another computer and the same name and history follow you; anyone holding that text can post as you, so treat it like a password.

The same panel has Delete everything, which is a real deletion behind a typed confirmation: your name, every message you posted, every reaction you left and every report you filed, then the key itself. It cannot be undone and nothing is kept.

Focus sessions & tab sleeping

Focus sessions

On the homepage, start a focus sprint and list the sites that derail you. For the length of the timer AIHub actually blocks them — try to open one and you land on a calm “come back later” page instead. When the timer ends, the block lifts on its own.

Tab sleeping

Tabs you haven’t touched in a while go to sleep and hand their memory back to the system, so a wall of open tabs stops slowing you down. A sleeping tab wakes the instant you click it. Want it now? Right-click any tab → Sleep Tab (free memory).

Per-site AI memory pairs well here: open the assistant on a site, hit the green Memory button, and jot standing instructions the AI should always apply on that site.

Cross-device handoff

Move your whole browsing session to your other computer in two clicks — through your own Google account, with nobody in the middle.

On the machine you’re leaving, open the command palette (Ctrl+K) and run Send my tabs to another device. Every open web page is bundled up and stored in a private, hidden folder inside your Google Drive.

On the other machine — signed into the same Google account and running AIHub — open the palette and run Open tabs from another device. Your tabs reopen exactly as they were, and the handed-off copy is cleared automatically.

StepWhere

Handoff uses Google Drive’s app-data space — a hidden per-app folder that never shows up in your Drive and that no other app can read. Connect Google in Settings (with Drive enabled) on each device once, and it just works. Nothing passes through any server we run.

About the animation

When the sphere opens, nodes don't just appear. The most-connected hubs pop in first on a spring that slightly overshoots and settles, mid-tier nodes follow, then the leaves — while edges draw themselves outward from source to target with a bright travelling tip. The camera dollies from pulled-back to fitted. Once settled, every node breathes gently, hubs a little more than leaves.

Timelapse takes that idea further: it empties the canvas and rebuilds your graph one node at a time in order of importance, roughly eight nodes a second, with a live progress bar. An edge only appears once both of its endpoints exist, and the physics keeps reflowing as the graph grows — so you watch your knowledge base assemble itself. Press Stop to bring everything back instantly.

Free VPN

No account, no subscription, no credentials. Sidebar → VPN, click a country, done.

Available locations: France, Belgium, Canada, United States, United Kingdom, Germany, Netherlands, Japan — plus Direct to turn it off.

How it works

  1. You click a country.
  2. The browser pulls a fresh list of free community servers for that country.
  3. It tests them in batches, and only accepts one that both responds and genuinely changes your public IP.
  4. The card shows live progress ("Testing 7/40"). Tap again to cancel.
Be realistic about free servers. They're community-run: speeds vary, servers come and go, and the first connection to a country can take up to half a minute while the browser hunts for a working one. Don't do banking through one. If a server drops, just reconnect and it finds another.

Have your own paid proxy? Advanced → Add your own proxy server supports SOCKS5, HTTP, and HTTPS with optional credentials.

Wi-Fi

Sidebar → Wi-Fi scans every network around you and lets you join any of them — open or secured.

  • Open networks connect with one click, no password.
  • Secured networks prompt for the password once, then Windows remembers it.
  • Saved networks show a Saved badge and reconnect in one click.
  • Real verification — the browser waits and confirms you actually associated, rather than claiming success immediately. A wrong password is reported honestly and the bad profile is cleaned up.
Wi-Fi management is Windows-only for now. On any open network, turn the VPN on before doing anything sensitive.

Sessions, workspaces & containers

Pick up where you left off, keep sets of tabs by name, and sign in twice to the same site.

Your tabs come back

Close the browser with fifteen tabs open and it reopens with fifteen tabs. Turn it off in Settings → Startup → Reopen my tabs.

The session that existed when you launched is also kept separately, so Ctrl+K → Reopen my previous session still works after the new window has moved on.

Workspaces

A workspace is a named set of tabs. Press Ctrl+K and run Save these tabs as a workspace — it names itself after what is in it (“tradingview + 3 more”). Open one later from the same palette, under Workspaces. Saving under a name you already used replaces it rather than piling up copies.

Site containers — two accounts, one browser

Containers are separate cookie jars with names. A tab opened in Work and a tab opened in Personal can be signed into the same site as different people, and a tracker inside one knows nothing about the other.

Press Ctrl+K and run New tab in Work (or Personal, or Shopping). In the vertical tab rail, a small coloured dot on a tab shows which container it belongs to.

Containers are per-device on purpose. They are never synced — a cookie jar means nothing on another machine, and shipping one across the network would be a liability rather than a convenience.

Obsidian vault & encrypted sync

Your reading becomes notes you own, and your bookmarks travel without anyone else reading them.

Save pages into Obsidian

Point AIHub at your vault folder in Settings → Obsidian. Then:

  • Right-click a page → Save Page to Obsidian. The readable text lands in AIHub/Clippings as markdown with frontmatter.
  • Select text first and choose Save Selection to Obsidian to keep just that passage, tagged highlight.

Notes are plain markdown with a source link, a date and tags — no plugin to install, and they stay readable if this browser disappears tomorrow. An existing note is never overwritten; a second save becomes “Note 2”.

Encrypted sync through your own Drive

Settings → Sync encrypts your bookmarks and preferences on this machine with a passphrase you choose, then parks the result in a hidden folder of your own Google Drive. Google stores something it cannot read.

  • Connect your Google account (Settings → Gmail) if you have not already.
  • Enter the same passphrase on each device.
  • Upload from the machine that is up to date, then Merge from cloud on the other one.
Only you hold the passphrase. There is no reset. If you lose it, the synced copy cannot be recovered — not by us, not by Google. That is the price of the browser genuinely not being able to read your bookmarks.

API keys, your vault path and container cookies are filtered out before encryption — they belong to the machine, not the account.

Moving to another computer

Everything you have made in AIHub goes into one file. Carry it on a USB stick, mail it to yourself, or keep it as a backup — then import it on the new machine and carry on where you left off.

How to do it

  1. On the old computer: Settings → Backup & move to another computer → Export everything, and save the .aihub file. It is also on the Bible page: open Saved and use Export there.
  2. Copy the file across — USB stick, email, cloud drive, whatever suits.
  3. On the new computer: Settings → Import from a file. You are shown exactly what is inside — verses, highlights, bookmarks, themes — and nothing is written until you confirm.

Privacy & security

  • Local AI option — with Ollama, nothing you type leaves your machine.
  • Keys stay local — API keys are stored on your device, never transmitted anywhere but the provider you chose.
  • OAuth done properly — Google sign-in uses PKCE in your system browser; tokens are encrypted at rest.
  • Web security stays on — pages run with full Chromium sandboxing.
  • Prompt-injection defense — text from pages, files, and command output is fed to the AI as data, and can't issue it commands.
  • Command approval — nothing executes on your system without an explicit click.

AIHub checks GitHub Releases for updates on startup and periodically, and tells you in-app when a new version ships.
